# DUST STRIKE Online

Браузерный 3D-шутер от первого лица на **Three.js** с поддержкой одиночной игры против ботов и мультиплеера (P2P через WebRTC / PeerJS).

## Режимы игры

* **Игра с ботами** — классический раунд за спецназ (CT) против отряда террористов с раундовой экономикой и покупкой оружия.
* **Локальный сервер** — создание приватной комнаты с уникальным кодом для игры с друзьями по прямой ссылке/коду.
* **Публичные сервера** — быстрое подключение к открытым комнатам (`RU Public #1`, `EU Public #2`, `Deathmatch #3`).

## Управление

| Клавиша / Действие | Описание |
| :--- | :--- |
| `W` `A` `S` `D` | Передвижение |
| `Space` | Прыжок |
| `Shift` | Тихий шаг |
| `Ctrl` / `C` | Присесть |

## Запуск и публикация

### Запуск онлайн (GitHub Pages)
1. Загрузите `index.html` и `README.md` в публичный репозиторий GitHub.
2. Перейдите в **Settings → Pages**, выберите ветку `main` и нажмите **Save**.
3. Откройте сгенерированную ссылку `https://<ваш-логин>.github.io/<имя-репозитория>/` в браузере.

### Локальный запуск
Для корректной работы сетевых функций (`WebRTC` / `Pointer Lock`) запускайте игру через локальный веб-сервер:
```bash
python -m http.server 8080
```
После запуска откройте `http://localhost:8080` в браузере.

## Технологии
* **Three.js (r128)** — 3D-графика, освещение, тени и рейкастинг.
* **PeerJS** — P2P-соединение между игроками без выделенного бэкенда.
* **Web Audio API** — процедурная генерация звуков выстрелов, шагов и попаданий.
